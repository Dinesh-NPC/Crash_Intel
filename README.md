# CrashIntel
### AI-Powered Road Accident Analysis & Prediction System

CrashIntel is a team project developed for the subject **Big Data and Analytics**.  
The project focuses on analyzing large-scale traffic accident datasets and predicting accident severity and fatality risks using Machine Learning and Big Data technologies.

The system provides an interactive dashboard, real-time prediction interface, and data-driven insights to improve road safety analysis.

---

#  Project Objectives

- Analyze traffic accident data efficiently using Big Data tools
- Predict accident severity using Machine Learning
- Identify fatal accident possibilities
- Visualize accident trends and statistics
- Build a user-friendly web application for prediction and analytics

---

## 1️⃣ Severity Prediction Model
Predicts the level of injury severity based on accident conditions.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/Dinesh-NPC/Crash_Intel.git
```

## Navigate to Project Folder

```bash
cd Crash_Intel
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Application

```bash
python app.py
```

Open in browser:

```bash
http://127.0.0.1:5000
```
